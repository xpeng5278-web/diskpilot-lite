# DiskPilot Lite P0 — 实现规格（给开发者/Codex）

DiskPilot Lite = WizTree 之上的「报告 + 清理建议」层（不是另一个分析器）。
目标用户：C 盘满了、完全不懂电脑的中国 Windows 用户。双击一次，得到一份报告。所有界面/控制台文字用中文。
**绝对不删除/移动任何用户文件**（唯一例外：脚本自己生成的那个 CSV 临时文件）。

## 已核实的外部事实（来源见 README「技术说明」）
- WizTree 命令行导出（https://diskanalyzer.com/guide#csvexport）：
  `WizTree64.exe "C:" /export="路径.csv" /admin=1 /exportfiles=0`（`/exportfiles=0` = 只导出文件夹，体积小得多）。
  WizTree 是 GUI 程序，要等它导出完成必须等待进程结束（官方说用 `start /wait`）；32 位 wiztree.exe 在 64 位系统会转启 wiztree64.exe 后立刻返回，所以优先用 WizTree64.exe。
  `/admin=1` 才能快速扫描（需要管理员；面向用户的文字不出现「MFT」）。
- CSV 格式：第 1 行通常是 `Generated by WizTree ...` 说明行，第 2 行表头
  `File Name,Size,Allocated,Modified,Attributes,Files,Folders`（4.25+ 默认还会在表头后追加磁盘容量相关列，列名未公开 → 必须按表头名找列，容忍额外列）。
  文件夹路径以 `\` 结尾；文件夹的 Size/Allocated 是其下所有内容的总和；文件的 Allocated 若以前导 0 开头（如 `04096`）表示硬链接，不计入占用。
  文件名用双引号包裹，内部 `"` 转义为 `""`。编码官方未写明 → 解析时自动识别：UTF-8 BOM / UTF-16LE BOM / 无 BOM 先按 UTF-8(fatal) 试，失败则 gb18030。
- winget：`winget install --id AntibodySoftware.WizTree -e --source winget --accept-package-agreements --accept-source-agreements --silent`；Inno 安装包，machine scope → 默认装到 `%ProgramFiles%\WizTree\WizTree64.exe`，卸载注册表键 `WizTree_is1`。安装包约 5–8 MB。
- WizTree 许可：个人免费；再分发需要付费 Distribution License → **不打包 WizTree**。

## zip 内容（扁平，目标 < 1 MB）
- `一键扫描C盘.cmd`（唯一的启动器，纯 ASCII，CRLF 行尾）
- `diskpilot-lite.ps1`（UTF-8 **带 BOM**，CRLF —— PowerShell 5.1 需要 BOM 才按 UTF-8 读中文）
- `看示例或导入CSV.html`（单文件报告查看器/模板，≤ 500 KB，内置示例数据，可直接双击打开）
- `使用说明.txt`（UTF-8 BOM，CRLF）

## .cmd 启动器要求
- 纯 ASCII；`@echo off`、`setlocal`、`chcp 65001 >nul`；所有路径用 `"%~dp0..."` 引号包裹；不要用延迟扩展；中文提示通过
  `powershell -NoProfile -ExecutionPolicy Bypass -Command "[Console]::OutputEncoding=[Text.Encoding]::UTF8; Write-Host (-join [char[]](0x8BF7,...))"` 输出（build 生成码点）。
  这些调用不要放在 `if ( ... )` 括号块里（用 goto 标签），避免括号/逗号问题。
- 第一步：`if not exist "%~dp0diskpilot-lite.ps1"` → 说明是在压缩包里直接运行 → 第一行输出「请先右键解压，再双击」+ 简短说明（右键 zip →「全部解压缩」→ 打开解压出的文件夹 → 双击 一键扫描C盘.cmd），`pause`，退出。
- 找不到 powershell.exe（`where powershell` 失败）→ 英文+拼音无法显示中文时也要 pause；用 `%SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe` 绝对路径优先。
- 调用：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File "%~dp0diskpilot-lite.ps1"`。ps1 自己负责所有正常流程的暂停并以 0 退出；若 powershell 返回非 0（例如脚本解析失败），cmd 输出中文「出错了」提示并 `pause`。任何路径都不能闪退。
- 必须在含空格、中文、括号的路径下可用。

## diskpilot-lite.ps1 流程（PowerShell 5.1 兼容：不用 `??`、三元、`&&`、`-Parallel`、`ForEach-Object -Parallel`、`Join-Path` 多参数等 7.x 语法）
全部 `-LiteralPath`；`$ErrorActionPreference='Stop'`；最外层 try/catch：任何异常 → 中文说明 + 原始错误信息 + 「按回车键关闭窗口」。
把可测试的纯函数放在前面，并支持 `. .\diskpilot-lite.ps1 -NoRun` 只加载函数不执行主流程（`param([switch]$NoRun)`），以便在 Linux 上用 pwsh 做单元测试。

1. 启动：`[Console]::OutputEncoding = UTF8`；标题行「DiskPilot Lite · C 盘空间报告」；说明「本工具只生成报告和建议，不会删除你的任何文件」。
2. 解压检测：若 `$PSScriptRoot` 下没有 `看示例或导入CSV.html`，或路径看起来是压缩包临时目录（匹配 `\Temp\d*_[^\\]*\.zip\\`、`\\Rar\$`、`\\7z[^\\]*\\` 且位于 %TEMP% 下）→ 第一行「请先右键解压，再双击」，暂停退出。
3. 查找 WizTree（函数 `Find-WizTree`，返回第一个存在的 WizTree64.exe，其次 WizTree.exe 仅在 32 位系统用）：
   `$env:WIZTREE_PATH`（可为 exe 或文件夹）→ 脚本同目录 → `%ProgramFiles%\WizTree` → `%ProgramFiles(x86)%\WizTree` → `%LOCALAPPDATA%\Programs\WizTree` →
   注册表 `HKLM/HKCU:\Software\Microsoft\Windows\CurrentVersion\Uninstall\WizTree_is1` 及 `HKLM:\Software\WOW6432Node\...\WizTree_is1` 的 `InstallLocation` → `where.exe WizTree64.exe`。
4. 未找到：
   - `Get-Command winget` 不存在 → 打印「请用浏览器打开官网 https://diskanalyzer.com/download 下载安装 WizTree（个人免费），装好后再双击本工具」，并告诉用户也可以直接打开 `看示例或导入CSV.html` 看示例或导入 CSV；暂停退出（不闪退）。
   - 存在 → 中文说明：「没有找到 WizTree（免费的磁盘扫描工具，本工具靠它读取 C 盘）。可以用 Windows 自带的 winget 从官方软件源安装：软件包 AntibodySoftware.WizTree，发布者 Antibody Software，大小约 5–8 MB。安装时 Windows 可能弹出一次管理员确认。」接着打印「安装即表示你同意 WizTree 的许可协议（个人免费），协议原文见：https://diskanalyzer.com/eula」，然后 `Read-Host`「输入 Y 并回车 = 安装；直接回车 = 不安装」。只有 `Y/y/Ｙ/ｙ` 才安装；其他（包括空）= 不安装 → 提示官网链接、暂停退出。
   - 安装：先说「正在下载安装，期间出现的英文进度信息是正常的，不需要你做任何选择」。执行
     `winget install --id AntibodySoftware.WizTree -e --source winget --accept-package-agreements --accept-source-agreements --silent`。完成后重新 Find-WizTree；仍找不到 → 中文说明 + 官网链接 + 暂停退出。
   - 这是整个流程里**唯一**会联网的步骤。
5. 临时 CSV 位置（函数 `Select-CsvFolder`）：先告诉用户「扫描结果会先存成一个临时表格文件，大约需要 50–200 MB 空间，生成报告后马上删除」。
   若 D: 存在且 `IsReady` 且 DriveType 为 Fixed 且剩余 > 500 MB → `D:\DiskPilotLite_temp\`；否则 `[IO.Path]::GetTempPath()` 下 `DiskPilotLite_temp\`（若该路径含非 ASCII 字符则改用 `C:\ProgramData\DiskPilotLite_temp\`）。记录文件夹是否由本脚本新建。
   文件名 `c-folders-yyyyMMdd-HHmmss.csv`（ASCII）。打印完整路径。
6. 提权说明：扫描前打印「接下来 Windows 会弹出『是否允许此应用对你的设备进行更改？』，请点『是』。原因：需要管理员权限才能快速读取磁盘，这样 1～2 分钟就能扫完。点『否』也行，但会改用慢速模式，可能要 10 分钟以上。」然后「按回车键继续」。
7. 扫描：`Start-Process -FilePath $wiz -ArgumentList $argString -Verb RunAs -PassThru`，`$argString = 'C: /export="' + $csv + '" /admin=1 /exportfiles=0'`（注意 PS 5.1 的 ArgumentList 不会自动加引号，要自己拼一整串；`C:` 不带反斜杠）。
   若用户拒绝 UAC（抛异常）→ 提示「你选择了不授权，改用慢速模式扫描」→ 不带 RunAs、`/admin=0` 再跑。
   等待期间保持窗口有动静：每秒刷新一行「正在扫描 C 盘，大约需要 1 到 2 分钟，请不要关闭这个窗口 … 已用 N 秒」+ 旋转字符（用 `Write-Host -NoNewline` + "`r"）。等 `$p.HasExited`，再额外等待 CSV 文件大小稳定（连续 2 次相同，最多 30 秒）。超时 30 分钟 → 报错暂停。CSV 不存在或为空 → 中文报错暂停。
8. 整理数据（函数 `Convert-WizTreeCsvToEmbed -CsvPath -MinBytes`，默认 MinBytes=10MB）：`System.IO.StreamReader`（`detectEncodingFromByteOrderMarks=$true`，默认 UTF8）逐行读；跳过 `Generated by` 说明行与表头（按表头名定位 File Name / Size / Allocated 列，找不到则假设 0/1/2）；
   只保留 **文件夹行**（路径以 `\` 结尾）且 Allocated ≥ MinBytes（根目录 `C:\` 行永远保留）；解析行时：若以 `"` 开头，路径到下一个 `",`（路径中的 `""` 还原为 `"`），其余按逗号切。
   输出紧凑 CSV 文本：表头 `File Name,Size,Allocated`，每行 `"路径",size,allocated`。打印「正在整理扫描结果…」+ 每 5 万行一次进度。
9. 生成报告（函数 `New-ReportHtml -TemplatePath -OutPath -CsvText -Meta`）：读模板（UTF-8），把
   `<script type="text/plain" id="dp-embedded-csv"></script>` 替换为包含 CsvText 的同名标签（把 `</` 替换为 `<\/`，防止提前闭合）；
   把 `<script type="application/json" id="dp-embedded-meta">null</script>` 替换为 meta JSON（`source:"real"`，`drive:"C:"`，`scannedAt` ISO 本地时间，`totalBytes`/`freeBytes` 取自 `[IO.DriveInfo]'C:'`，`minFolderBytes`，`exportKind:"folders"`，`adminScan:true/false`）。
   用 `New-Object Text.UTF8Encoding $false` 写出到 `$PSScriptRoot\C盘报告-yyyyMMdd-HHmm.html`；若该目录不可写 → 写到桌面？**不**，写到 `[IO.Path]::GetTempPath()` 并打印路径。
10. `Start-Process -FilePath $reportPath` 打开报告；打印「报告文件：<完整路径>（想留就留，不想要可以直接删）」。
11. 等 2 秒后删除 CSV：先打印「正在删除临时文件：<完整路径>」，只 `Remove-Item -LiteralPath $csv`（不用通配符、不用 -Recurse）；若文件夹是本脚本新建且现在为空，用 `[IO.Directory]::Delete($dir, $false)` 删掉空文件夹（非空则保留）。删除失败 → 告诉用户可以手动删这个文件。
12. 最后一行「报告已打开，可以关掉这个窗口了」，然后 `Read-Host` 等回车。
13. 除了第 4 步 winget，脚本没有任何网络访问。

## 报告页 看示例或导入CSV.html（build 把 core.js、rules.js、demo-data.js、app.js、style.css 内联进 src/report.html）
- `<meta charset="utf-8">` + CSP：`<meta http-equiv="Content-Security-Policy" content="default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data:; connect-src 'none'; form-action 'none'; base-uri 'none'">`。零网络请求：无外链字体/CDN/图片/favicon（用 `<link rel="icon" href="data:,">`）。≤ 500 KB。
- 数据来源优先级：内嵌 meta/csv（脚本生成）→ 内嵌 result（「保存这份报告」生成）→ 内置示例数据。
- 页面顶部固定条：「DiskPilot Lite · C 盘清理建议」、醒目标签「仅建议、不删除」（始终可见，position: sticky/fixed）、隐私说明「全部在本机完成：不联网、不上传、不删除任何文件」、醒目按钮「保存这份报告」。
- 数据来源说明：「数据来源：示例数据（不是你的电脑）」或「数据来源：真实扫描 · C: · 2026-09-28 11:03」或「数据来源：你导入的 CSV（文件名）」。示例时额外提示如何获得真实报告（双击 一键扫描C盘.cmd，或导入 CSV）。
- 首屏大字：「这些建议最多涉及约 X GB，实际能腾出多少，要看你最后清了哪些」，旁边小「?」图标（可聚焦，hover/focus/点击显示提示）「同一个文件夹只算一次，不会重复加总」。X = 所有建议项路径的并集大小（嵌套路径只算最外层）。下面一行「你已勾选：约 Y GB」随勾选变化；若有 C 盘总/剩余则显示。
- 清单：三个档位标签页 轻度（放心清）/ 中度（在软件里清）/ 重度（先看再清），每个标签显示该档合计；勾选项目改变「已勾选」和档位数字；空档显示「这一档暂无可勾建议」。每个建议项：名称、大小、涉及路径（最多 3 条，其余「等 N 处」）、「去哪里清」（只是指引文字，**不提供任何删除/移动按钮**），风险提示。存储感知类建议写「打开 设置 > 系统 > 存储 > 临时文件」，并给一个 `ms-settings:storagesense` 链接（链接文字写清是打开 Windows 设置）。勾选状态存在内存（可选 localStorage，失败不影响）。
- 分类概览：条形图列出各分类大小（系统与 Windows / 已安装的软件 / 应用数据与缓存(AppData) / 个人文件 / 下载 / 回收站 / 其他与根目录文件）。
- 「保存这份报告」：生成独立 HTML（当前页面同一套代码 + 把当前聚合结果 JSON 和勾选状态写进内嵌 script 标签，恢复 #app 初始 DOM），通过浏览器下载保存（`<a download>` Blob），文件名 `DiskPilot报告-YYYY-MM-DD.html`（本地日期）。之后在按钮下方提示：「已保存到浏览器的「下载」文件夹，文件名是 DiskPilot报告-日期.html，按 Ctrl+J 可以直接打开下载记录」（写真实文件名；不声称完整路径，不承诺避开 C 盘）。保存的文件再次打开必须显示同样结果（数据来源保留原来的真实/示例标注 + 「已保存的报告」）。
- 备用入口「用自己导出的 CSV 生成报告」：拖拽区 +「选择 CSV 文件」按钮（`<input type=file accept=".csv,.tsv,text/csv">`），支持 WizTree 文件列表 CSV 和文件夹列表 CSV（含 `Generated by` 说明行与否都行）。三步指引：
  1）打开 WizTree，左上角选「C:」，点「扫描」(Scan)；2）扫描完按 Ctrl+Alt+E（或在左侧树里右键 C: → "Export to CSV file..."，中文界面叫「导出到 CSV 文件」类似名称）；3）保存到 D 盘或 U 盘（不要存 C 盘），然后把文件拖进来或点「选择 CSV 文件」。
  读取：`File.slice` 分块（4 MB），`TextDecoder(…, {stream:true})`，按 BOM 选编码，无 BOM 用 UTF-8 fatal 探测首块失败则 gb18030；每块之间让出事件循环；进度条 + 文字「正在本机读取，不会上传… 37%」。中文路径不能乱码。完成后替换当前报告。解析失败显示中文错误。
- 全部中文、字号大、对比度高、窄屏可用。

## core.js（共享、纯 JS、可在浏览器和 Node 跑）
- `createCsvParser({onRow})`：`push(textChunk)` / `end()`；处理跨块断行、CRLF、引号字段与 `""`、前导 BOM、`Generated by` 说明行（表头前最多跳过 5 行非表头）、按名字找列（file name/文件名/文件名称、size/大小、allocated/分配/已分配），容忍额外列；硬链接前导 0 → allocated=0；空 allocated 用 size。行对象 `{path, isDir, size, allocated}`。
- `createAggregator({ rules })`：`add(row)` / `result()`。
  * 占用量统一用 allocated。
  * **建议项（rules）**：每条规则 `{id, tier:'light'|'medium'|'heavy', name, patterns:[...], where, risk}`；pattern 是小写路径段数组，`*` 匹配任意一段，首段 `**` 表示任意深度（锚点为第一次出现处）；盘符段总是通配。路径命中后得到「锚点路径」= 匹配到的前缀目录。
    文件夹行路径 == 锚点 → 记录该锚点 folderBytes；文件行在锚点之下 → 累加 fileBytes；最终锚点大小 = folderBytes（若有）否则 fileBytes。同一路径第一条命中的规则生效（规则顺序即优先级）。
  * 每条规则按大小排序后最多保留 300 个锚点（`allAnchors`），结果另保留前 50 个锚点明细；`anchorCount` 记录截断前的数量。聚合结果和保存 JSON 均采用此上限，并集与建议合计只使用截断后的列表。
  * **去重**：`unionBytes(anchorPaths)` —— 路径排序后，若某锚点的祖先也在集合里就跳过；最大值 X 与「已勾选」都用它，保证同一个文件夹只算一次。导出给 UI 的 result 需要足够信息让 UI 在勾选时重新算并集（即每项锚点列表）。
  * **分类概览**：用「分桶」得到互不重叠的集合：`\Windows\`→system；`\Program Files\`、`\Program Files (x86)\`→programs；`\ProgramData\`→appdata（程序公共数据）；`\Users\<u>\AppData\`→appdata；`\Users\<u>\Downloads\`→downloads；`\Users\<u>\{Desktop,Documents,Pictures,Videos,Music,OneDrive*}\`→personal；`\$Recycle.Bin\`→recycle；`\Users\<u>\<其他>\` 与其他顶层文件夹→other。
    文件行：按其所在桶累加；文件夹行：仅当文件夹路径正好是桶路径时计入。根 `C:\` 文件夹行给出总量；「其他与根目录文件（含 pagefile.sys、hiberfil.sys 等）」= 根总量 − 各桶之和（≥0）。纯文件列表时总量 = 所有文件之和。
  * result：`{ totalBytes, rowCount, fileRows, folderRows, skipped, kind:'files'|'folders'|'mixed', categories:[{id,label,bytes}], suggestions:[{id,tier,name,where,risk,bytes,anchors:[{path,bytes}],anchorCount}], maxBytes }`（suggestions 只含 bytes>0 的）。
- `formatBytes`（中文，GB 保留 1 位，如「约 12.3 GB」「850 MB」）。
- `decodeHelpers`：`sniffEncoding(uint8Array)` 返回 'utf-8'|'utf-16le'|'gb18030'。
- 性能目标：100 万行 < 5 秒（Node 20）。避免每行正则回溯和大对象分配；路径小写后 split 一次；规则按第二段（users/windows/...）预分组，`**` 规则单独检查。
